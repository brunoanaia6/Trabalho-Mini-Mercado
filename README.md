# Mini Mercado - Projeto Java

## Descrição

Sistema de terminal (console) desenvolvido em Java para gerenciamento de um mini mercado.

O sistema permite:

* Cadastro de produtos
* Cadastro de clientes
* Consulta de produtos e clientes
* Alteração de registros
* Remoção de registros
* Realização de compras
* Controle de estoque
* Persistência de dados utilizando arquivos CSV

## Tecnologias Utilizadas

* Java
* NetBeans
* Arquivos CSV

## Como Executar

### Requisitos

* JDK 17 ou superior
* NetBeans IDE

### Passos para execução

1. Baixe ou clone o repositório.
2. Abra o projeto no NetBeans.
3. Execute a classe `MiniMercado.java`.
4. Utilize o menu principal para acessar as funcionalidades do sistema.
